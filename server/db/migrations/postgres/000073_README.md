# 000073 commercial image 2.6 models

Adds the 2.6 image family to the Free pool and to the paid image packages:

- `gpt-image-2.6`, `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst` carry 100 CNY
  each, the per-model image amount 000021 (paid) and 000024 (Free) established.
- Only the three new keys are written, with the `jsonb ||` operator:
  `catsco-free`, `catsco-personal`, `catsco-pro` and
  `catsco-internal-all-models-50k` keep every other budget key. Production edits
  those maps in place (catsco-free currently sells a single MiniMax-M3 budget),
  and a literal rewrite would silently revert that data.
- The advertised Free pooled allowance rises 2200 -> 2500 (twelve models), the
  Personal total 11000 -> 11300 and the Pro total 33000 -> 33300.
- Active free entitlements receive one `grant_type='free'` grant per new model;
  every other active package on those plans receives one grant per new model at
  100 CNY, mirroring the grant type, interval and `source_ref` it already
  carries (the 000021 shape). Both paths are guarded, so the migration is
  repeatable.
- Manual grants, order snapshots and all other plans are untouched.
- Running the down migration removes only the three budget keys and revokes
  only the grants this migration stamped (`CatsCo free image 2.6 model access`
  / `Public plan image 2.6 model access`), recording the matching revoke rows
  in `commercial_quota_ledger`.

Note: the model-set migrations are no longer part of the startup statement list
(they reverted operator edits on every restart), so this one has to be applied
by number with `up.sql`. `schema_commercial_image26_models.go` keeps a
byte-identical copy for the parity test.
