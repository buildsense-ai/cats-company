# 000023 commercial free image models

Opens the image lane to the Free plan so image generation is available on
every public plan:

- `catsco-free` gains the five image-lane models (`gpt-image-2`, `gpt-image-2.5`,
  `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst`, `chatgpt-image-latest`) at
  100 CNY each, the same per-model amount the Personal plan grants.
- The advertised Free pooled allowance rises 1800 -> 2300 (+500), mirroring
  000022's DeepSeek Flash add to Free.
- Existing active free entitlements receive one grant per image model; the
  `NOT EXISTS` guard keeps the migration repeatable on every startup.
- Paid plans (`catsco-personal` 100 / `catsco-pro` 300 per image model),
  manual grants and order snapshots are untouched.
