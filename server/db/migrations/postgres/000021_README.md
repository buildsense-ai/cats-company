# Public image model access

Migration 000021 adds the image lane models (gpt-image-2, gpt-image-2.5,
gpt-image-2.5-flare, gpt-image-2.5-sunburst, chatgpt-image-latest) to
`catsco-personal` (Pro) and `catsco-pro` (Max) on top of the five public chat
models. The advertised pool grows by the add-on: 10500 -> 11000 and
31500 -> 33000. Image calls draw from the same shared pool as the chat models.

Open order snapshots are updated. Existing public packages, including future
renewals, receive the image grants at their original interval; the five chat
grants stay untouched. Internal/custom plans, manual/internal grants and
fulfilled history are preserved. The startup migration uses the same SQL and can
run repeatedly. The down migration removes only the add-on grants created here.

No Relay package change is required: the relay loads its model catalog
dynamically and classifies image models by name, so the add-on flows through the
existing scopes/budget sync once the plan grants exist.
