# CatsCo Contact Page

## Direction

- Match the current homepage and pricing page with a neutral graphite `#171717` canvas, `#202020` form surface, restrained neutral lines, and CatsCo green reserved for the title accent, status rail, focus states, and primary action.
- Treat the page as a concise consultation brief rather than a generic lead-generation form. The left column explains the meaningful sequence of goal, authorized environment, and expected result; the right column remains the single form surface.
- Keep the left brief sticky only while the two-column layout is active. The form uses two columns where space allows and returns to one column on small screens.
- Avoid decorative gradients, glow, glass effects, and ornamental illustrations. Hierarchy comes from typography, surface contrast, spacing, and one green rule on the form panel.
- Use restrained 160–220ms interaction feedback and honor `prefers-reduced-motion`.

- Use a two-column desktop layout and a single-column mobile layout.
- Keep visible labels, useful autocomplete and inline feedback.
- The current form is a visual prototype; submission feedback must state that information was validated locally but not sent.
- Required fields show field-level errors, focus moves to the first invalid field, and the submit action is named for local checking rather than sending.
- Keep the unavailable contact-service notice visible before the form is used; do not invent an email address or persistence promise.
- Support `topic=enterprise` and `topic=download` query parameters so the page preserves the user's intent.
