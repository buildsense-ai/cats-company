# 液态主题密码权限

CatsCo 的“液态”外观使用纯前端密码验证，不调用后端权限或兑换接口。前端仅保存不可逆的密码验证值和本地解锁状态，不保存密码明文。

## 解锁约定

- 密码验证完全在浏览器中通过 Web Crypto 完成。
- 客户端只保存用户当前选择的主题和本地解锁标记，不保存主题密码。
- 未解锁时选择液态主题会显示密码输入框。
- 清除浏览器站点数据后需要重新输入密码。
- 纯前端门槛不能替代服务端权限控制，不应用于保护敏感数据或付费内容。

## 测试步骤

1. 用户在“设置与资料 → 外观 → 液态”中输入密码。
2. 验证成功后主题立即切换。
3. 刷新页面后仍可使用液态主题。
4. 清除站点数据后确认主题重新锁定。

开发环境可以用 `?theme_preview=liquid` 直接预览材质。该入口只在 Vite 开发模式生效，不会在 production build 中绕过权益验证。
