# 套餐界面预览

在 `webapp/` 中运行 `npm start`，打开 `/plans-preview.html`。

- 个人套餐草案：¥59、¥99、¥159 / 月；Token 额度为 5 亿、约 10 亿、约 20 亿。
- 企业图文布局：`/plans-preview.html?enterprise=e`，使用中性浮雕背景。
- 企业页新增团队版草案：¥599 / 月，最多 10 人，最高 30 亿 Token，独享 4 核 8 GB 服务器；包含团队经验与 Skill 沉淀、共享知识库和团队权限管理。按钮打开既有购买确认，实际支付仍被预览拦截。
- 顶部“企业排版”可切换 A–E 五种布局；主题可切换浅色、深色、液态。

预览复用套餐及购买确认组件，并在入口中提供示例目录和展示内容。所有订单、支付、试用和邀请码写入均被本地拦截，不调用真实接口，也不修改线上价格或后端权益。

此页面仅用于 Vite 开发预览，不加入生产构建入口。咨询企业落地保留原联系页面链接。

实际应用已通过共享组件接入相同方案：登录后从「套餐与权益 → 升级套餐」进入，或打开 `/?open=relay`。用量、已有权益和订单仍读取真实接口。展示方案只有与服务端目录的 slug、价格、币种和有效期一致且目录开放时才允许购买；未匹配的方案可查看确认信息，但不会创建订单。独立预览仍拦截所有写入。
